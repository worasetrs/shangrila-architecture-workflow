# Netlify deployment

This repository is ready for a zero-build Netlify deployment.

## Recommended deployment
1. Connect the GitHub repository in Netlify.
2. Select this repository.
3. Build command: leave empty.
4. Publish directory: `.`
5. Deploy.

`netlify.toml` already sets the publish directory to the repository root and adds basic security headers.

## Privacy note
This repository does not include the source PDFs or original design files. If you later add drawings, renders, DWGs, or Blender source assets to the repository, decide whether the repository/site should remain private before publishing them.
