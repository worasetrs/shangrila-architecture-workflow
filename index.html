Verify in PDF/source
01 · อาคารฝั่งขวา

ตรวจ massing / façade / balcony / side wall / roof profile เทียบกับ plan/elevation/section ใน PDF ก่อน ถ้าดูต่างจากภาพ 3D ให้บันทึก mismatch โดยยังไม่สรุปว่าต้องแก้ทั้งอาคาร

02 · อาคารฝั่งซ้าย

ตรวจว่า source drawing ของอาคารนี้อยู่ในไฟล์ใดและตรงกับภาพ 3D แค่ไหน ห้ามฟันธงว่าต้องสร้างแบบใหม่จนกว่าจะตรวจ source ครบ

03 · Pavilion กลาง

ตรวจตำแหน่งและสัดส่วนจาก PDF/site plan ก่อน ภาพ perspective ใช้เป็น visual target แต่ไม่ใช้วัด footprint

04 · Guardhouse / ทางเข้า

ใช้ภาพล่าสุดตรวจรูปลักษณ์และองค์ประกอบ แต่ driveway, turning, curb/island, setback ต้องอ้างจากแบบหรือค่าที่ผู้ใช้ยืนยัน

05 · Pods / อาคารย่อย

ตรวจว่ามีในชุด PDF หรือไม่ ถ้าไม่มีให้เปิด issue และขอ scope/function ก่อนเขียน plan/elevation/section

06 · Parking / circulation

ถ้าภาพ render ดูต่างจาก master/site plan ให้ตรวจจำนวนช่องจอดและแนวทางวิ่งจาก source ก่อน ไม่กะระยะจากภาพ

07 · Pool / landscape

ใช้ PDF/site plan เป็นฐาน geometry และใช้ภาพ render เป็น design reference สำหรับรูปทรง/บรรยากาศที่ต้องการ

08 · Source version

ต้องกำหนด baseline ว่า Master Plan, Architectural PDF และภาพ reference ใดเป็นฉบับที่ใช้อ้างในแต่ละเรื่อง พร้อมบันทึกใน SOURCE_REGISTER
