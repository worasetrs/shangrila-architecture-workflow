01 · อาคารหลักฝั่งขวา

massing / façade / balcony / side wall / roof profile ใน 3D ล่าสุดดูไม่ตรงกับรูปด้านและแปลนชุดเดิม ต้องเทียบด้วย Top/Front/Side Orthographic จากโมเดลจริง

02 · อาคารฝั่งซ้าย

3D ล่าสุดแสดงอาคารเป็นองค์ประกอบหลักชัดเจน ต้องมีชุดแบบของอาคารนี้เอง ไม่ควรดัดแบบอาคารขวาไปใช้แทน

03 · Pavilion กลาง

ตำแหน่งและสัดส่วนอาคารกระจกส่วนกลางต้อง export footprint จาก 3D แล้ว overlay กับ site plan

04 · Guardhouse / ทางเข้า

3D ล่าสุดใช้ป้อมยามขนาดเล็กและ barrier ชิดทางเข้า ต้องแก้ driveway, turning, curb/island และ setback ที่เกี่ยวข้อง

05 · Pods / อาคารย่อย

มีอาคารย่อยรอบอาคารฝั่งขวาที่ไม่ชัดในชุดแบบเดิม ต้องกำหนดหน้าที่และสร้าง plan/elevation/section เมื่อเป็นงานก่อสร้างจริง

06 · Parking / circulation

รูปแบบช่องจอดและทางรถวิ่งใน 3D ดูต่างจาก master/site plan เดิม ต้องนับและตรวจระยะจริงใหม่ทั้งหมด

07 · Pool / landscape

concept ใกล้เคียงเดิม แต่ shape/deck/island/ระยะจากอาคารต้อง trace จาก top view ของโมเดลใหม่ ไม่ใช้ภาพ perspective กะระยะ

08 · Source version

ไฟล์ master plan ที่แยกออกมากับ site plan ในชุดสถาปัตย์ใช้มาตราส่วนต่างกัน จึงต้องตั้ง Revision Baseline ว่าไฟล์ใดเป็นตัวล่าสุดก่อนแก้
